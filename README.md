## Запуск локально
1) клонировать либо скачать архив проекта
2) Установить зависимости командной ```bash npm run i```
3) Собрать проект ```bash npm run build```
4) Запустить проект ```bash npm run start```

## Структура проекта

- `src/app` — Маршруты страниц.
- `src/features/stop-list/model` — бизнес-логика стоп-листа, запросы TanStack Query и схема валидации.
- `src/features/stop-list/ui` — клиентские компоненты списка, фильтров и модального окна.
- `src/shared` — переиспользуемое состояние Zustand, UI-компоненты и общие утилиты.
- `src/types` — TypeScript-типы.

## Серверные и клиентские компоненты
На стороне сервера отрабатывают `layout.tsx`, `page.tsx`, `not-found.tsx`, API routes, и компоненты из shared так как они не требуют клиентской логики
Всё остальное использует 'use client' так как требуют обработку на стороне клиента
